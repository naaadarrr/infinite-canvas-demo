# Phase 3: Avatar 家族接入说明

## 概述

Phase 3 包含四个工具，均依赖大量 tRPC 接口（模板列表、收藏、任务创建、TTS、媒体库等）。目标仓库无 tRPC，需将下列接口改为你项目的直接请求（如 axios）。

| 工具 | 说明 | 复杂度 |
|------|------|--------|
| **AI Avatar** | 选择/上传数字人模板 + 输入文案/语音 → 生成口播视频 | 高 |
| **Product Avatar** | 商品图 + 模板 + 口播/文案 → 商品讲解视频；含抠图、去背景、Character Swap 等子任务 | 很高 |
| **Design My Avatar** | 用 Prompt 或照片生成「我的头像」模板，再用于 AI Avatar / Product Avatar | 高 |
| **Video Lip Sync** | 选择/上传数字人 + 视频/音频/文案 → 口型同步视频 | 高 |

**技术栈**：Recoil + Tailwind 不变；**API 层**全部需替换（每个工具涉及 5～15+ 个 tRPC 接口）。

## 二、各工具需替换的 tRPC 接口清单

### 2.1 AI Avatar

| 用途 | tRPC 路径 | 说明 |
|------|-----------|------|
| 创建口播视频任务 | `trpc.avatar4.createPhotoAvatar4Task` | 核心提交接口 |

## 三、接入步骤（通用）

1. **复制**：将 `reference/phase3-avatar/` 下 `AiAvatar`、`ProductAvatar`、`DesignMyAvatar`、`VideoLipSync` 四个目录完整复制到目标项目 `ToolPanel/feature/Avatar/`。
2. **替换 API**：按上表逐个将 `trpc.xxx.yyy` 改为你项目的请求函数（axios/fetch），请求体与响应格式需与现网或后端约定一致。
3. **替换 import**：`@/lib/utils`、`@/hooks/useToast`、`@/store/benefit`、`useActiveTabId`、`useBoardTaskManager`、`useViewMode`、`usePricingModal`（`@topview/pricing`）、`useAwsS3`、`useS3Upload`、权限/权益相关（`checkUserSufficientPermission`、`teamBenefitInfoState`、`RESOURCE_SUBS_TYPE` 等）等，按你项目路径或实现替换/写死。
4. **注册**：在侧边栏 config 中增加：
   ```ts
   [ToolType.AiAvatar]: AiAvatar,
   [ToolType.ProductAvatar]: ProductAvatar,
   [ToolType.DesignMyAvatar]: DesignMyAvatar,
   [ToolType.VideoLipSync]: VideoLipSync,
   ```

---

## 四、建议接入顺序

1. **AI Avatar**：核心是 `avatar4.createPhotoAvatar4Task` + 模板/分类/收藏/媒体库接口；TTS、免费次数可先占位或写死。
2. **Video Lip Sync**：与 AI Avatar 共用大量媒体库与模板能力，接口形态接近，可紧接着接。
3. **Design My Avatar**：依赖 `promptToAvatar` 创建任务 + AiAvatar/ProductAvatar 的模板与收藏能力，适合在 1、2 或 Product Avatar 部分接口就绪后接。
4. **Product Avatar**：子任务多（去背景、图角色替换、视频重生成等），接口最多，建议最后接；若你后端暂无部分子任务，可先隐藏对应入口或做占位。

## 五、共享依赖说明

- **common.favorite**（add/cancel）：四个工具都会用到，建议封装成你项目统一的「收藏」API。
- **mediaLibrary.aiAvatar**（getCustomAiAvatarList、createPhotoAvatar、updateAvatarVoice、deleteCustomAvatar）：AiAvatar、DesignMyAvatar、VideoLipSync 共用，可统一替换为一个模块。
- **avatar4** 分类/模板/收藏/集合：AiAvatar、DesignMyAvatar 共用，同一套后端即可。
- **productAvatar.template**：ProductAvatar、DesignMyAvatar 共用。
- **定价/权益**：多处依赖 `@topview/pricing`、`teamCreditState`、`teamBenefitInfoState`、权限校验，需用你项目的定价与权益模块替代或暂时写死通过。

完成上述替换与 import 调整后，按「建议接入顺序」逐个在侧边栏打开验证即可。
