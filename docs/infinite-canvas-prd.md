## 1. 产品定位

### 1.1 是什么

**无限画布（Canvas）** 是 Board 的视图模式之一（Grid / Split / Grouped / **Canvas**），提供一个自由的二维空间，创作者可以在其中随意摆放、浏览和**直接创作** AI 素材（图片、视频、音频、文字）。

### 1.2 不是什么

- **不是节点流工具**（如 ComfyUI）——没有连线、条件分支、执行管线。
- **不是设计工具**（如 Figma）——不提供矢量绘图、布尔运算、组件系统。

### 1.3 核心价值

| 维度 | Grid 模式 | Canvas 模式 |
|------|----------|-------------|
| 空间 | 固定网格排列 | 自由二维空间 |
| 创作 | 左侧面板生成 → 右侧展示 | 画布即创作台，素材就地生成 |
| 组织 | 按时间/类型自动排列 | 手动拖放，空间语义分组 |
| 协作 | 各自独立操作 | 实时多人协同（光标、选中、拖拽同步） |

### 1.4 术语说明

| 术语 | 含义 |
|------|------|
| **素材** | 画布上的一个内容元素：图片 / 视频 / 音频 / 文字 |
| **占位素材** | 用户触发 AI 创作但尚未生成的素材，带有工具名称标记 |
| **QuickActionToolbar** | 选中素材后出现在上方的快捷操作栏 |
| **创作面板** | AI 创作时，跟随素材显示的参数输入面板 |
| **Scheme B** | 本次迭代的布局方案：左侧固定工具栏 + 底部中央控制栏 |

## 5. Inpaint 交互流程（完整规格）

Inpaint 是 Canvas 模式中最复杂的单一工具交互，分为**两个步骤**：上传步骤和涂抹步骤。

### 5.1 入口方式

| 入口 | 触发条件 | 进入哪个步骤 |
|------|----------|-------------|
| 左侧侧边栏 → Image → Inpaint | 画布上无选中图片，从零开始 | **上传步骤**（step: 'upload'） |
| 选中图片 → QuickActionToolbar → Inpaint（🖌） | 画布上已有图片素材 | **涂抹步骤**（step: 'edit'） |

---

### 5.2 上传步骤（step: 'upload'）

**触发行为：**
1. 画布中央自动创建一个 **260×260px** 占位节点（`NodeType.IMAGE`，`url: ''`，`toolId: 'inpaint'`）
2. 同时进入 `inpaintFocus.step = 'upload'` 状态
3. 占位节点居中于有效画布区（排除左侧 64px 侧边栏和底部 64px 工具栏）

**界面结构：**

```
┌────────────────────────────────────────────────────────────┐
│ [🏠]  侧边栏保持可见                                         │
│ [Board]                                                     │
│ [🖼]                                                        │
│ [🎬]       ■─────────────────■  ← 四角缩放把手（白色正方形）  │
│ [👤]       │                 │                             │
│ [🎤]       │   🖼            │  ← 占位节点（深色背景）       │
│ [🎤]       │  Click to upload│                             │
│            │                 │                             │
│            │─────────────────│                             │
│            │ □□ Select from  │  ← "从 Board 选择" 按钮     │
│            │    Board        │                             │
│            ■─────────────────■                             │
├────────────────────────────────────────────────────────────┤
│  [↖] [✋] [+] [模板] [−] 42% [+] [Layers]  ← 底部栏始终可见 │
└────────────────────────────────────────────────────────────┘
```

**占位节点规格：**
- 初始大小：**260×260px**（flow 坐标系，非屏幕像素）
- 初始位置：画布有效区中央
- 背景色：`rgba(20,21,24,0.92)`
- 边框：`2.5px solid #5857FD`（无圆角）
- 无 `borderRadius`（直角）

**四角缩放把手：**
- 尺寸：**12×12px**，`borderRadius: 2`
- 颜色：白色背景 + `2px solid #5857FD` 边框
- 拖拽行为：等比缩放（基于对角锚点距离比）；最小尺寸 80px
- 定位：以 `position: absolute` 挂在父容器外四角

**拖拽移动：**
- 鼠标按下并移动（>4px 阈值）→ 拖动占位节点
- 如果未移动就松开 → 触发上传（`INPAINT_UPLOAD_IMAGE` 事件）

**点击行为：**
- 点击占位节点内部（上传区域）→ 触发 `INPAINT_UPLOAD_IMAGE` 事件（宿主处理文件选择）
- 点击"Select from Board"→ 触发 `CANVAS_NAVIGATE { target: 'board-select', context: 'inpaint' }` 事件
- 点击占位节点外的画布空白区 → 取消 Inpaint，删除占位节点

**图片上传完成后：**
- 宿主通过 `INPAINT_IMAGE_UPLOADED { nodeId, url }` 事件通知
- 自动切换到**涂抹步骤**（step: 'edit'，`uploadedImageUrl` 填入）

---

### 5.3 涂抹步骤（step: 'edit'）

**从 QuickActionToolbar 进入的居中行为：**
- 不新建节点，使用已选中的图片节点
- 计算可用画布区域（排除：左侧边栏 64px，顶部遮罩工具栏约 68px，底部工具栏 64px，底部 Inpaint 面板约 180px）
- 在可用区内以 **75% 填充比** 居中缩放节点，动画时长 300ms

**界面结构：**

```
┌────────────────────────────────────────────────────────────┐
│ [🏠]                    ┌────────────────────────────┐     │
│ [Board]                 │ 🖌  −  ─────────  ↩ ↪ ✓  │  ← 涂抹工具栏（节点正上方）
│                         └────────────────────────────┘     │
│ [🖼]                                                        │
│ [🎬]               ┌──────────────────────────────┐        │
│ [👤]               │                              │        │
│ [🎤]               │    🖼 图片（已选中）           │        │
│                    │    [涂抹遮罩层叠加在图片上]    │        │
│                    │                              │        │
│                    └──────────────────────────────┘        │
│                    ┌──────────────────────────────┐        │
│                    │ Inpaint               ×       │  ← Inpaint 操作面板
│                    │ [Reference] Describe...       │
│                    │                  [Generate ↑] │
│                    └──────────────────────────────┘        │
├────────────────────────────────────────────────────────────┤
│  [↖] [✋] [+] [模板] [−] 221% [+] [Layers]  ← 底部栏可见   │
└────────────────────────────────────────────────────────────┘
```

**涂抹工具栏（悬浮在图片正上方）：**

| 控件 | 类型 | 说明 |
|------|------|------|
| 🖌 Brush | 按钮 | 切换为画笔（涂抹模式） |
| ◻ Eraser | 按钮 | 切换为橡皮擦（清除遮罩） |
| ─── Slider | 滑块 | 调整笔刷大小（5 ~ 80px） |
| ↩ Undo | 按钮 | 撤销上一步涂抹 |
| ↪ Redo | 按钮 | 重做 |
| ✓ Done | 按钮 | 关闭 Inpaint 模式 |

工具栏定位：通过 `requestAnimationFrame` 实时跟随节点位置，平滑跟随缩放/平移。

**自定义笔刷光标：**
- 圆形光标，大小 = `brushSize × viewport.zoom`
- 颜色：`#facc15`（黄色轮廓）
- 进入涂抹区时显示，离开后隐藏
- 画笔模式和橡皮擦模式共用同一光标

**Inpaint 操作面板（底部中央浮层）：**

```
┌──────────────────────────────────────────┐
│  Inpaint                            ×    │  ← 标题栏，× 关闭
├──────────────────────────────────────────┤
│  ┌──────┐  Describe what you want to     │
│  │ Ref+ │  change, or enter a prompt     │  ← 左：参考图上传；右：Prompt 输入框
│  │      │  for the masked area           │
│  └──────┘                                │
│                              [Generate ↑]│  ← 生成按钮（有 Prompt 时激活）
└──────────────────────────────────────────┘
```

- 宽度：`min(440px, 视口宽度 - 160px)`
- 位置：`bottom: 64px`（悬浮在底部工具栏上方），水平居中于画布可用区
- `borderRadius: 14px`

**生成按钮激活规则：**
- Prompt 非空 → 白色背景 + 黑色文字 + 阴影，可点击
- Prompt 为空 → 灰色背景，不可点击（`cursor: default`）

**Inpaint 提交：**
- 按 Enter（非 Shift+Enter）→ 提交
- 点击 Generate 按钮 → 提交
- 提交后触发 `NODE_QUICK_ACTION { actionId: 'inpaint', prompt, maskTool, brushSize }` 事件

**退出 Inpaint 模式：**
- 按 Esc
- 点击工具栏 ✓ Done
- 点击 Inpaint 面板 × 关闭

### 5.4 Inpaint 状态流转

```
用户点击侧边栏 Image → Inpaint
        │
        ▼
创建占位节点（260×260，url 为空）
进入 inpaintFocus { step: 'upload' }
        │
        ├─ 用户点击占位节点 ──────────────────► INPAINT_UPLOAD_IMAGE 事件
        │                                      宿主完成选图后回调 INPAINT_IMAGE_UPLOADED
        │                                              │
        │   ┌──────────────────────────────────────────┘
        │   ▼
        │  切换到 inpaintFocus { step: 'edit', uploadedImageUrl }
        │
        ├─ 用户点击 Select from Board ────────► CANVAS_NAVIGATE { target: 'board-select' }
        │                                      宿主选完后回调 INPAINT_IMAGE_UPLOADED
        │
        └─ 用户点击画布空白 ─────────────────► 取消，删除占位节点

用户选中图片 → QuickActionToolbar → 🖌 Inpaint
        │
        ▼
进入 inpaintFocus { step: 'edit' }
画布自动居中到图片（排除 UI 占用区域）
        │
        ├─ 用户涂抹 + 输入 Prompt → Generate ─► NODE_QUICK_ACTION { inpaint, prompt, maskTool }
        │
        └─ Esc / ✓ / × ─────────────────────► 退出 inpaintFocus，回到常规状态
```

---

### 5.5 Inpaint 状态隔离（工程注意事项）

> **重要**：Inpaint 使用独立的 `inpaintFocus` 状态，**与 `aiCreateMode` 完全解耦**。

- 进入 Inpaint 后，`aiCreateMode` **不得被激活**
- 侧边栏条件：`!aiCreateMode`（`inpaintFocus` 不影响侧边栏可见性）
- 底部工具栏条件：`!aiCreateMode`（同上）
- 占位节点的 `toolId: 'inpaint'` 必须在「重新激活创作面板」的 `useEffect` 中明确排除：
  ```ts
  if (nodeAny.toolId === 'inpaint') return;  // Inpaint 占位节点不触发 aiCreateMode
  ```

## 7. 素材

### 7.1 素材类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 图片 | 已生成或上传的静态图 | AI 生图、用户上传的照片 |
| 视频 | 已生成或上传的动态视频 | AI 生视频、本地 mp4 |
| 音频 | AI 生成的音频 | Voiceover 语音 |
| 文字 | 用户创建的文字标注 | 备忘文字、标题 |

### 7.2 素材状态

| 状态 | 视觉效果 | 何时出现 |
|------|----------|----------|
| 默认 | 无边框 | 未选中、未操作 |
| Hover | 轻微高亮 | 鼠标悬停 |
| 选中 | 尺寸标签 + QuickActionToolbar + 四角缩放把手 | 点击素材 |
| 拖拽中 | 保持选中，隐藏操作栏 | 拖动素材 |
| 生成中 | 骨架屏 / loading 动画 | AI 正在生成 |
| 失败 | 红色边框 + 错误提示 | AI 生成失败 |

### 7.3 缩放把手（四角）

所有类型素材选中后，四角出现缩放把手：

```
■───────────────■
│               │
│               │
│               │
■───────────────■
```

- 大小：`12 / zoom` px（随缩放比例调整，保持视觉一致）
- 样式：白色背景 + `2px solid #5857FD` 边框 + `borderRadius: 2`
- 鼠标样式：对角线方向对应 `nwse-resize` 或 `nesw-resize`
- 拖拽：等比缩放（锚点为对角角落）；最小宽高 80px/60px

### 7.4 占位素材

当用户从工具栏触发 AI 创作时，画布中心会创建一个**占位素材**——它代表"即将生成的内容"：

```
┌─────────────────────┐
│                     │
│      🖼             │  ← 类型图标（图片/视频/音频）
│   Image Upscale     │  ← 工具名称
│                     │
└─────────────────────┘
```

- 深色实底背景 + 类型图标 + 工具名称
- 创建后**永久保留**在画布上，直到生成完成或被用户手动删除
- 记住对应的工具类型和用户已填的参数，再次点击可恢复创作面板

**Inpaint 占位素材特殊规则：**
- 初始大小 **260×260px**（比普通 AI 占位素材小，避免占满视口）
- 不带工具名称标签，仅显示上传 UI
- 没有 `borderRadius`（直角边框）
- 支持拖动和缩放（四角把手）
- 用户上传图片后，占位素材转变为正式图片节点，进入涂抹步骤

## 9. AI 创作面板（Canvas 模式）

### 9.1 设计思路

Canvas 模式的创作面板**不是** Grid 模式面板的照搬，而是为沉浸式画布体验量身定制的**精简版**：

| 原则 | 说明 |
|------|------|
| **Prompt 优先** | 文字描述是主角，占据面板最大区域 |
| **核心参数内联** | Model / Resolution / Ratio 等放在底栏，一行搞定 |
| **高级参数隐藏** | Number of Images、Multi-shot 等用默认值，通过设置图标展开 |
| **面板跟随素材** | 悬浮在占位素材正下方，随画布缩放平移 |

> **核心原则**：让用户在画布上"说一句话就出图"，复杂调参留给 Grid 模式。

### 9.2 面板分类

按核心交互方式分为 4 类：

---

**A 类 — Prompt 驱动型**

以文字描述为核心输入，可选附带参考图。

```
┌──────────────────────────────────────────┐
│                                          │
│  What are we creating today              │
│                                          │
│                                          │
├──────────────────────────────────────────┤
│ 🍌 Model ▾  │ 📷  │   1K ▾  1:1 ▾  ⚡14│
└──────────────────────────────────────────┘
  模型选择    参考图   分辨率 比例  积分+发送
```

适用工具：
- **Text to Image** — 底栏：Model ▾ | 📷 参考图 | Resolution ▾ | Ratio ▾ | ⚡积分
- **Image Edit** — 底栏：Model ▾ | 📷 参考图(已含) | Resolution ▾ | Ratio ▾ | ⚡积分
- **Text to Video** — 底栏：Model ▾ | Resolution ▾ | Ratio ▾ | Duration ▾ | ⚡积分

---

**B 类 — 上传驱动型**

以素材上传为核心，参数极简，无需 Prompt。

```
┌──────────────────────────────────────────┐
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │                                   │  │
│  │        ⬆ Upload Image             │  │
│  │                                   │  │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
├──────────────────────────────────────────┤
│  Target Resolution   2K ▾        ⚡ 4   │
└──────────────────────────────────────────┘
```

适用工具：
- **Image Upscale** — 上传图 + Resolution ▾
- **Video Upscale** — 上传视频 + Resolution ▾
- **Photo Angle Editor** — 上传图 + 3D Camera 控件（交互特殊，需保留相机预览区）

---

**C 类 — 多素材组合型**

需要上传多个素材（如目标图 + 角色图），无 Prompt。

```
┌──────────────────────────────────────────┐
│  Target Image                            │
│  ┌─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─┐           │
│  │ Upload   │  │ Select     │           │
│  │ Photo    │  │ Avatar     │           │

│  Character Image                         │
│  ┌─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─┐           │
│  │ Upload   │  │ Select     │           │
│  │ Photo    │  │ Avatar     │           │
│  └─ ─ ─ ─ ─┘  └─ ─ ─ ─ ─ ─┘           │

│                                   ⚡ 10  │
└──────────────────────────────────────────┘
```

适用工具：
- **Image Character Swap** — Target Image + Character Image
- **Image Face Swap** — Face Image + Target Image
- **Video Character Swap** — Target Video + Character Image
- **Motion Control** — Character Image + Motion Reference Video + Quality ▾

---

**D 类 — 混合型**（上传 + Prompt）

同时需要上传素材和文字描述。

```
┌──────────────────────────────────────────┐
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │        ⬆ Upload Image             │  │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                                          │
│  Describe what you want to change...     │
│                                          │
├──────────────────────────────────────────┤
│  📷 参考图(可选)                  ⚡ 10  │
└──────────────────────────────────────────┘
```

适用工具：
- **Inpaint** — 上传图（或自动填入已选中的图片）+ Prompt + 可选参考图
- **Image to Video** — 上传首尾帧 + Prompt + Model ▾ | Resolution ▾ | Duration ▾
- **Omni Reference** — 上传视频 + 参考图 + Prompt + Model ▾ | Resolution ▾

---

**E 类 — 脚本驱动型（Avatar 专用）**

以"形象 + 脚本 + 配音"为核心。

```
│  │ ⬆ Upload │  │ 🔲 Select Template  │  │
│  └─ ─ ─ ─ ─┘  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                                          │
│  Script (Text to Audio)                  │
│  ┌────────────────────────────────────┐  │

├──────────────────────────────────────────┤

```

适用工具：
- **AI Avatar** — 上传/模板 + 脚本 + 配音
- **Video Lip Sync** — 视频源 + 脚本 + 配音

## 10. 占位素材（草稿）与工具绑定

### 10.1 核心概念

占位素材是 Canvas 模式的**专属概念**，本质是一个"创作草稿"——用户选择了工具、可能填了部分参数，但还没有提交生成。

> **关键区别**：在 Grid 模式下，只有用户点击"Generate"后才会产生任务记录。Canvas 模式允许用户先"占个位"，稍后再创作。

### 10.2 占位素材的生命周期

```
用户点击工具栏 Image → Inpaint
        │
        ▼
画布中心出现占位素材（260×260，显示上传 UI）
        │
        ├── 用户上传图片
        │       → 进入涂抹步骤（inpaintFocus.step = 'edit'）
        │       → 用户涂抹 + 输入 Prompt → Generate
        │       → 生成完成 → 新图片出现在旁边
        │
        └── 用户手动删除 / 点击空白取消
                → 占位素材从画布移除
```

### 10.3 跨视图一致性

**方案：草稿为 Canvas 专属状态，对 Grid 不可见**

| 场景 | 行为 |
|------|------|
| Canvas 中创建占位素材 | 出现在画布上 + Layers 面板中（带 ✏️ 草稿标记） |
| Canvas 中提交生成 | 草稿 → 生成中 → 正式素材（所有视图可见） |
| 切换到 Grid 模式 | 草稿**不显示**，只展示正式素材 |
| 切回 Canvas 模式 | 草稿仍在原来位置，参数保留 |

## 14. 附：桥接事件一览（工程接口）

Canvas 组件通过事件桥（`widgetBridge`）与宿主通信，以下是 Inpaint 相关事件：

| 事件名 | 方向 | 触发时机 | Payload |
|--------|------|----------|---------|
| `INPAINT_UPLOAD_IMAGE` | Canvas → 宿主 | 用户点击占位节点（上传步骤） | `{ nodeId }` |
| `INPAINT_IMAGE_UPLOADED` | 宿主 → Canvas | 用户选完图片 | `{ nodeId, url }` |
| `INPAINT_UPLOAD_REFERENCE` | Canvas → 宿主 | 用户点击参考图上传区 | `{ nodeId, slotIndex }` |
| `INPAINT_MASK_ACTION` | Canvas → 宿主 | 撤销/重做涂抹 | `{ action: 'undo' \| 'redo' }` |
| `NODE_QUICK_ACTION` | Canvas → 宿主 | 提交 Inpaint 生成 | `{ nodeId, actionId: 'inpaint', prompt, maskTool, brushSize }` |
| `CANVAS_NAVIGATE` | Canvas → 宿主 | 点击「Select from Board」 | `{ target: 'board-select', context: 'inpaint', nodeId }` |

完整桥接事件文档见 [`AGENT.command-api.md`](../AGENT.command-api.md)。
