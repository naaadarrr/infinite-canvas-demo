# 无限画布改版 — 产品需求文档 v13

---

## 1. 产品定位

### 1.1 是什么

**无限画布（Canvas）** 是 Board 的视图模式之一（Grid / Split / Grouped / **Canvas**），提供一个自由的二维空间，创作者可以在其中随意摆放、浏览和**直接创作** AI 素材（图片、视频、音频、文字）。

### 1.2 不是什么

- **不是节点流工具**（如 ComfyUI）——没有连线、条件分支、执行管线。
- **不是设计工具**（如 Figma）——不提供矢量绘图、布尔运算、组件系统。

### 1.3 核心价值

| 维度 | Grid 模式 | Canvas 模式 |
|------|----------|-------------|
| 空间 | 固定网格排列 | 自由二维空间 |
| 创作 | 左侧面板生成 → 右侧展示 | 画布即创作台，素材就地生成 |
| 组织 | 按时间/类型自动排列 | 手动拖放，空间语义分组 |
| 协作 | 各自独立操作 | 实时多人协同（光标、选中、拖拽同步） |

### 1.4 术语说明

| 术语 | 含义 |
|------|------|
| **素材** | 画布上的一个内容元素：图片 / 视频 / 音频 / 文字 |
| **占位素材** | 用户触发 AI 创作但尚未生成的素材，带有工具名称标记 |
| **QuickActionToolbar** | 选中素材后出现在上方的快捷操作栏 |
| **创作面板** | AI 创作时，跟随素材显示的参数输入面板 |

## 7. 素材

### 7.1 素材类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 图片 | 已生成或上传的静态图 | AI 生图、用户上传的照片 |
| 视频 | 已生成或上传的动态视频 | AI 生视频、本地 mp4 |
| 音频 | AI 生成的音频 | Voiceover 语音 |
| 文字 | 用户创建的文字标注 | 备忘文字、标题 |

### 7.2 素材状态

| 状态 | 视觉效果 | 何时出现 |
|------|----------|----------|
| 默认 | 无边框 | 未选中、未操作 |
| Hover | 轻微高亮 | 鼠标悬停 |
| 选中 | 尺寸标签 + QuickActionToolbar | 点击素材 |
| 拖拽中 | 保持选中，隐藏操作栏 | 拖动素材 |
| 生成中 | 骨架屏 / loading 动画 | AI 正在生成 |
| 失败 | 红色边框 + 错误提示 | AI 生成失败 |

### 7.3 占位素材

当用户从工具栏触发 AI 创作时，画布中心会创建一个**占位素材**——它代表"即将生成的内容"：

```
┌─────────────────────┐
│                     │
│      🖼             │  ← 类型图标（图片/视频/音频）
│   Image Upscale     │  ← 工具名称
│                     │
└─────────────────────┘
```

- 深色实底背景 + 类型图标 + 工具名称
- 创建后**永久保留**在画布上，直到生成完成或被用户手动删除
- 记住对应的工具类型和用户已填的参数，再次点击可恢复创作面板

## 10. AI 创作面板（Canvas 模式）

### 10.1 设计思路

Canvas 模式的创作面板**不是** Grid 模式面板的照搬，而是为沉浸式画布体验量身定制的**精简版**：

| 原则 | 说明 |
|------|------|
| **Prompt 优先** | 文字描述是主角，占据面板最大区域 |
| **核心参数内联** | Model / Resolution / Ratio 等放在底栏，一行搞定 |
| **高级参数隐藏** | Number of Images、Multi-shot 等用默认值，通过设置图标展开 |
| **面板跟随素材** | 悬浮在占位素材正下方，随画布缩放平移 |

> **核心原则**：让用户在画布上"说一句话就出图"，复杂调参留给 Grid 模式。

### 10.2 面板分类

按核心交互方式分为 4 类：

---

**A 类 — Prompt 驱动型**

以文字描述为核心输入，可选附带参考图。

```
┌──────────────────────────────────────────┐
│                                          │
│  What are we creating today              │
│                                          │
│                                          │
├──────────────────────────────────────────┤
│ 🍌 Model ▾  │ 📷  │   1K ▾  1:1 ▾  ⚡14│
└──────────────────────────────────────────┘
  模型选择    参考图   分辨率 比例  积分+发送
```

适用工具：
- **Text to Image** — 底栏：Model ▾ | 📷 参考图 | Resolution ▾ | Ratio ▾ | ⚡积分
- **Image Edit** — 底栏：Model ▾ | 📷 参考图(已含) | Resolution ▾ | Ratio ▾ | ⚡积分
- **Text to Video** — 底栏：Model ▾ | Resolution ▾ | Ratio ▾ | Duration ▾ | ⚡积分

> 底栏中 📷 图标点击后弹出上传浮层，上传后显示为缩略图。
> 高级参数（Number of Images、Multi-shot、Native Audio 等）可通过 ⚙ 展开。

---

**B 类 — 上传驱动型**

以素材上传为核心，参数极简，无需 Prompt。

```
┌──────────────────────────────────────────┐
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │                                   │  │
│  │        ⬆ Upload Image             │  │
│  │                                   │  │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
├──────────────────────────────────────────┤
│  Target Resolution   2K ▾        ⚡ 4   │
└──────────────────────────────────────────┘
```

适用工具：
- **Image Upscale** — 上传图 + Resolution ▾
- **Video Upscale** — 上传视频 + Resolution ▾
- **Photo Angle Editor** — 上传图 + 3D Camera 控件（交互特殊，需保留相机预览区）

---

**C 类 — 多素材组合型**

需要上传多个素材（如目标图 + 角色图），无 Prompt。

```
┌──────────────────────────────────────────┐
│  Target Image                            │
│  ┌─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─┐           │
│  │ Upload   │  │ Select     │           │
│  │ Photo    │  │ Avatar     │           │
│  └─ ─ ─ ─ ─┘  └─ ─ ─ ─ ─ ─┘           │
│            ⇅                             │
│  Character Image                         │
│  ┌─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─┐           │
│  │ Upload   │  │ Select     │           │
│  │ Photo    │  │ Avatar     │           │
│  └─ ─ ─ ─ ─┘  └─ ─ ─ ─ ─ ─┘           │
├──────────────────────────────────────────┤
│                                   ⚡ 10  │
└──────────────────────────────────────────┘
```

适用工具：
- **Image Character Swap** — Target Image + Character Image
- **Image Face Swap** — Face Image + Target Image
- **Video Character Swap** — Target Video + Character Image
- **Motion Control** — Character Image + Motion Reference Video + Quality ▾

---

**D 类 — 混合型**（上传 + Prompt）

同时需要上传素材和文字描述。

```
┌──────────────────────────────────────────┐
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │        ⬆ Upload Image             │  │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                                          │
│  Describe what you want to change...     │
│                                          │
├──────────────────────────────────────────┤
│  📷 参考图(可选)                  ⚡ 10  │
└──────────────────────────────────────────┘
```

适用工具：
- **Inpaint** — 上传图（或自动填入已选中的图片）+ Prompt + 可选参考图
- **Image to Video** — 上传首尾帧 + Prompt + Model ▾ | Resolution ▾ | Duration ▾
- **Omni Reference** — 上传视频 + 参考图 + Prompt + Model ▾ | Resolution ▾

---

**E 类 — 脚本驱动型（Avatar 专用）**

以"形象 + 脚本 + 配音"为核心。

```
┌──────────────────────────────────────────┐
│  Avatar Photo                            │
│  ┌─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │ ⬆ Upload │  │ 🔲 Select Template  │  │
│  └─ ─ ─ ─ ─┘  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                                          │
│  Script (Text to Audio)                  │
│  ┌────────────────────────────────────┐  │
│  │ Enter your script here...          │  │
│  │ (0/450)                            │  │
│  └────────────────────────────────────┘  │
│                                          │
├──────────────────────────────────────────┤
│  👩 Violet ▾ (Voice)              ⚡ 5   │
└──────────────────────────────────────────┘
```

适用工具：

## 11. 占位素材（草稿）与工具绑定

### 11.1 核心概念

占位素材是 Canvas 模式的**专属概念**，本质是一个"创作草稿"——用户选择了工具、可能填了部分参数，但还没有提交生成。

> **关键区别**：在 Grid 模式下，只有用户点击"Generate"后才会产生任务记录。Canvas 模式允许用户先"占个位"，稍后再创作。

### 11.2 占位素材的生命周期

```
用户点击工具栏 Image → Photo Angle Editor
        │
        ▼
画布中心出现占位素材（标记为草稿，显示 "Photo Angle Editor"）
占位素材下方自动弹出创作面板
        │
        ├── 用户点击画布空白区域
        │       → 创作面板收起，占位素材保留（仍为草稿）
        │       → 用户再次点击该素材 → 面板恢复（之前填的参数仍在）
        │
        ├── 用户填完参数并提交
        │       → 草稿状态结束，开始生成（显示 loading）
        │       → 生成完成 → 替换为正式素材（图片/视频/音频）
        │
        └── 用户手动删除
                → 占位素材从画布移除
```

### 11.3 跨视图一致性

**问题**：Canvas 中的占位素材（草稿），在切换到 Grid 模式时如何处理？Grid 模式只展示已完成的素材，没有"草稿"概念。

**方案：草稿为 Canvas 专属状态，对 Grid 不可见**

| 场景 | 行为 |
|------|------|
| Canvas 中创建占位素材 | 出现在画布上 + Layers 面板中（带 ✏️ 草稿标记） |
| Canvas 中提交生成 | 草稿 → 生成中 → 正式素材（所有视图可见） |
| 切换到 Grid 模式 | 草稿**不显示**，只展示正式素材 |
| 切回 Canvas 模式 | 草稿仍在原来位置，参数保留 |
| 在 Grid 模式中生成新素材 | 正式素材，Canvas 中也能看到（出现在默认位置） |

**Layers 面板中的草稿展示**：

```
┌───────────────────────┐
│  Layer            ⌄   │
├───────────────────────┤
│  🖼 90年代洗车广告风格  │  ← 正式素材
│  🖼 90年代自助洗车店    │  ← 正式素材
│  ✏️ Photo Angle Editor │  ← 草稿（半透明 + 铅笔图标）
│  ✏️ Text to Image      │  ← 草稿
└───────────────────────┘
```

> 草稿在 Layers 中用半透明样式 + ✏️ 图标区分，让用户一眼识别哪些素材还没有完成创作。

### 11.4 关键行为

1. 占位素材（草稿）是 **Canvas 专属**的，不同步到 Board 的正式素材列表
2. 再次点击占位素材可**恢复创作面板**，且之前的参数仍在
3. 按 Esc 可退出创作模式（面板收起，草稿保留）
4. 用户可在画布上同时创建多个不同工具的草稿
5. 草稿**可以被拖拽**移动位置、被删除，但不能被下载/复制
6. 生成成功后，草稿自动升级为正式素材，对所有视图可见

## 14. 补充设计

### 14.1 QuickAction → 创作面板的衔接

用户选中一张图片，点击 QuickActionToolbar 中的操作按钮后，分两种情况：

**A. 产生新素材的操作**（Generate Video / Edit Angles / Upscale / AI Avatar）

```
用户选中图片 A → 点击 "Generate Video"
        │
        ▼
图片 A 右侧（偏移 40px）自动创建占位素材 "Image to Video"
        │
        ▼
创作面板弹出，图片 A 已自动填入 "Upload Image" 区域
        │
        └── 用户补充 Prompt → 提交 → 生成完成后，占位素材变为视频
```

关键规则：
- 新的占位素材出现在**原素材右侧**，保持空间关联（"这个视频是从那张图派生的"）
- 原素材**自动填入**创作面板的上传区，减少重复操作
- 原素材保持不变，不会被替换或删除

**B. 原地操作**（Re-edit / Remix / Inpaint）

```
用户选中图片 A → 点击 "Inpaint"
        │
        ▼
进入 Inpaint 模式，聚焦到图片 A
图片 A 上方出现涂抹工具栏，下方出现 Prompt 输入
        │
        └── 用户涂抹 + 填 Prompt → 提交 → 生成新图片，出现在图片 A 旁边
```

关键规则：
- Re-edit：重新打开原始创作面板，参数预填，生成结果**替换**当前素材
- Remix：基于当前图生成新图，结果出现在**旁边**（不替换原图）
- Inpaint：原地编辑，结果出现在**旁边**

### 14.2 生成失败后的处理

```
┌══════════════════════┐
║  ⚠ Generation failed ║  ← 红色边框
║                      ║
║  Insufficient credits║  ← 错误原因
║                      ║
║  [↻ Retry] [✎ Edit]  ║  ← 两个操作按钮
└══════════════════════┘
```

| 操作 | 行为 |
|------|------|
| **Retry** | 用相同参数重新提交生成（如果是积分不足，充值后可重试） |
| **Edit** | 素材回退为草稿状态，重新打开创作面板，用户可修改参数后再次提交 |
| **Delete** | 右键删除即可 |

失败的素材在 Layers 面板中显示 ⚠️ 图标。不会自动消失，需要用户主动处理。

### 14.3 Undo / Redo

| 可撤销 | 不可撤销 |
|--------|----------|
| 拖拽移动位置 | AI 生成提交（消耗积分） |
| 删除素材 | 上传完成的文件 |
| 创建文字 | 视图切换（Grid ↔ Canvas） |
| 调整层级（Forward/Backward 等） | |
| 复制素材 | |
| 素材缩放/旋转 | |

- 快捷键：**⌘Z** 撤销 / **⌘⇧Z** 重做
- 历史深度：**50 步**
- 切换视图模式时历史记录清空（Canvas 操作历史不带到 Grid）

### 14.5 多选与批量操作

**触发方式**：
- 在空白区域拖拽框选
- 按住 ⌘ 逐个点击追加选中
- ⌘A 全选

**多选时的 QuickActionToolbar**：

```
┌───┬───┬───┐
│ ⬇ │ 📋│ 🗑│
└───┴───┴───┘
 下载 复制 删除
```

只保留通用操作，不显示 AI 相关操作（如 Remix、Inpaint 等仅对单个素材有意义）。

**多选时的右键菜单**：

```

├───────────────┤

```

多选素材可整体拖拽移动，保持相对位置不变。

### 14.6 素材详情

Canvas 模式以沉浸创作为主，素材详情采用**轻量方案**——右键菜单新增 "Info" 选项，点击后弹出气泡卡片：

```
┌──────────────────────────┐
│  90年代洗车广告风格         │
├──────────────────────────┤
│  工具    Text to Image    │
│  模型    Nano Banana 2    │
│  Prompt  "90年代复古洗车…"  │
│  分辨率  1024 × 1024      │
│  创建    2026-02-27 14:30 │
│  积分    14               │
├──────────────────────────┤
│  [复用参数]  [查看原图]     │
└──────────────────────────┘
```

- 气泡出现在素材旁边，点击空白区域关闭
- **复用参数**：以当前参数创建新的草稿，方便快速迭代
- **查看原图**：在新标签页中打开原始分辨率图片
- 对于上传的素材（非 AI 生成），只显示文件名、尺寸、上传时间

### 14.7 Grid 新增素材在 Canvas 中的位置

用户在 Grid 模式下生成了新素材，切回 Canvas 时：

**方案：自动排列在画布下方**

```
┌──────────────────────────────┐
│   [已有素材]  [已有素材]       │
│   [已有素材]  [已有素材]       │
│                              │
│ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈  │  ← 现有内容下边界
│                              │
│   [新素材1]  [新素材2]        │
│   [新素材3]                  │
│                              │
└──────────────────────────────┘
```

规则：
1. 计算画布上现有素材的**最下边界**
2. 新素材从下边界 + 间距开始，按网格排列
3. 切回 Canvas 时，如果有新素材，自动 Fit to Screen 展示全貌
4. 用户之后可自由拖拽重新组织

> 与 Grid 模式"从上到下"的阅读习惯一致——新素材出现在下方，不打乱已有的空间布局。

### 14.8 性能策略（后续版本）

- 素材数量建议上限 **500 个**
- 视口外的素材使用缩略图替代原图渲染
- 视频素材默认显示首帧静态图，鼠标 hover 时才加载预览
- 缩放比例低于 30% 时，素材简化为色块 + 标签
