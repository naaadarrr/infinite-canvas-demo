# Phase 2: Video 家族接入说明

## 概述

Phase 2 包含两类工具：

| 工具 | 类型 | 说明 |
|------|------|------|
| **AIVideo** | 共享组件 | 一个入口组件，内部分 Tab：Image to Video、Text to Video、Video Edit |
| **Video Upscale** | 独立组件 | 上传视频 + 选择分辨率(1080p/2K/4K) + 生成，与 Image Upscale 结构类似 |

**技术栈**：Recoil + Tailwind 不变；**API 层**需将 tRPC 改为你项目的直接请求（如 axios）。

---

## 一、Video Upscale（建议先接）

### 1.1 目录与文件

```
reference/phase2-video/VideoUpscale/
├── 接入说明.md          # 本 Phase 统一说明在上级 接入说明.md
├── api-types.ts         # API 类型（已提取，无 tRPC 依赖）
├── api-service.ts       # API 调用（直接 axios）
├── index.tsx            # 主组件
├── config.ts            # 分辨率、积分/分钟、S3 路径、时长限制
├── store/atoms.ts       # Recoil atomFamily
├── hooks/
│   ├── useVideoUpscaleForm.ts
│   ├── useVideoUpscaleTaskGeneration.ts
│   ├── useFillVideoUpscaleInput.ts
│   └── useVideoUpscaleReEditHandler.ts
└── data/task/useMutations.ts   # 需替换为 api-service
```

### 1.2 接入步骤（与 Phase 1 Image Upscale 一致）

1. **复制**：将 `VideoUpscale/` 下所有文件复制到目标项目 `ToolPanel/feature/Video/VideoUpscale/`。
2. **替换 API**：在 `data/task/useMutations.ts` 中，将 `trpc.videoUpscale.createTask.useMutation()` 改为调用 `api-service.ts` 的 `createVideoUpscaleTask`；查询同理改为 `queryVideoUpscaleTask`。`hooks/useVideoUpscaleTaskGeneration.ts` 里 `mutateAsync(params)` 改为 `createVideoUpscaleTask(params).then(r => r.result)`。
3. **请求体**：创建任务必填字段为 `inputVideoPath`、`resolution`、`duration`（秒）。前端在提交前会从视频元数据得到 `videoDuration`，在 `buildTaskParams` 里传入。
4. **替换 import**：与 Phase 1 相同，按你项目替换 `@/lib/utils`、`@/hooks/useAwsS3`、`@/hooks/useToast`、`@/utils/file`、`@/store/benefit`、`useActiveTabId`、`useAssetSelect`、`useBoardTaskManager`、`useViewMode`、`GenerateButton*`、`CreditBadge`、`MediaType` 等。
5. **注册**：在侧边栏 config 中增加 `[ToolType.VideoUpscale]: VideoUpscale`。

### 1.3 Video Upscale API 端点

- **创建任务**：`POST /common_task/video_flash_vsr/submit`  
  Body: `{ inputVideoPath, resolution: "1080p"|"2K"|"4K", duration（秒）, source?, boardTaskId?, ... }`  
  响应: `{ code, message, result: "taskId" }`

- **查询任务**：`GET /common_task/video_flash_vsr/detail?taskId=xxx`  
  响应: `{ code, message, result: { taskId, status, inputVideoPath, inputVideoUrl, outputVideoUrl, ... } }`

## 二、AIVideo（Image to Video / Text to Video / Video Edit）

### 2.1 结构说明

- **一个组件**：`AIVideo/index.tsx` 根据当前 `ToolType`（或 URL/state）渲染三个子面板之一：
  - `ImageToVideo`：图生视频
  - `TextToVideo`：文生视频
  - `VideoEdit`：视频编辑
- **共享状态**：`store/atoms.ts` 的 `aiVideoFormFamily(tabId)` 存模型、提示词、参考图等，三个子工具共用。
- **依赖多**：模型配置、灵感库、定价弹窗、积分、权限、S3 上传、Prompt 历史等，均依赖你项目现有能力。

### 2.2 目录与 API 点

```
reference/phase2-video/AIVideo/
├── index.tsx                    # 主入口，Tab 切换 + 生成逻辑
├── config.ts
├── store/atoms.ts
├── ImageToVideo/index.tsx       # 图生视频表单
├── TextToVideo/index.tsx        # 文生视频表单
├── VideoEdit/index.tsx          # 视频编辑表单
├── components/                  # Inspiration、ReferenceToVideoParameter、VideoFrameUploadParameter
├── helpers/                     # buildInspirationPreset, capability, pricing, promptConverter
├── hooks/                       # useAIVideoForm, useAIVideoTaskGeneration, useAIVideoGenerateGuard, useVideoModelConfig, useAIVideoReEditHandler, useCreateAiVideoProject
├── data/
│   ├── useMutations.ts          # useSubmitAiVideoTaskMutation -> 需替换
│   ├── useQueries.ts            # useAiVideoConfigQuery, useVideoInspirationQuery, useVideoInspirationCollectionsQuery, useVideoInspirationDetailQuery -> 需替换
│   └── aiVideo.json             # 静态配置
└── ...
```

**需要替换的 API（tRPC → 直接调用）：**

| 用途 | 原 tRPC | 说明 |
|------|---------|------|
| 提交任务 | `trpc.aiVideo.submitAiVideoTask` | 提交 AI 视频任务，参数见 `@/server/api/services/aiVideo/type` 的 `AiVideoTaskSubmitParam` |
| 模型/定价配置 | `trpc.aiVideo.getAiVideoConfig` | 返回模型列表、提供商、定价等 |
| 视频灵感列表 | `trpc.common.inspiration.queryVideoInspiration` | 分页列表 |
| 视频灵感集合 | `trpc.common.inspiration.queryVideoInspirationCollections` | 集合列表 |
| 视频灵感详情 | `trpc.inspiration.videoDetail` | 单个 template 详情 |

后端若未提供上述接口，需要你按现有后端能力封装成相同形状的 API，或在目标项目中先做占位/精简（例如只保留提交任务 + 简单模型列表）。

### 2.3 接入建议

1. **先接 Video Upscale**，再接 AIVideo，避免一次改太多。
2. AIVideo 先**只接一个子工具**（如 Image to Video）：复制 `AIVideo`、`ImageToVideo`、共享 store 与 `useAIVideoTaskGeneration`，把 `useQueries`/`useMutations` 换成你项目的请求，隐藏或写死 Text to Video / Video Edit 的 Tab，再逐步放开。
3. **权限与定价**：原实现依赖 `@topview/pricing`、`teamBenefitInfoState`、`checkUserSufficientPermission` 等，需在你项目中用现有权限/定价模块替代或暂时写死。

### 2.4 注册

在侧边栏 config 中增加三条映射（同一组件）：

```ts
[ToolType.ImageToVideo]: AIVideo,
[ToolType.TextToVideo]: AIVideo,
[ToolType.VideoEdit]: AIVideo,
```

---

## 三、建议顺序

1. 按 **Phase 1 的 Image Upscale** 方式，先完成 **Video Upscale**（复制 → 换 API → 换 import → 注册）。
2. 再按 **2.3** 的方式分步接入 **AIVideo**（先一个子工具，再补全 API 与其余 Tab）。

完成 Video Upscale 后即可在侧边栏使用「视频放大」；AIVideo 可按你后端能力分阶段接入。
