## 🎯 关键技术点

### 1. OAuth 2.0 授权码流程

```
1. 用户点击登录
   ↓
2. 重定向到飞书授权页
   URL: https://open.feishu.cn/open-apis/authen/v1/authorize
   参数: app_id, redirect_uri, state
   ↓
3. 用户确认授权
   ↓
4. 飞书回调应用
   URL: {redirect_uri}?code=xxx&state=xxx
   ↓
5. 应用使用 code 换取 access_token
   API: /open-apis/authen/v1/oidc/access_token
   ↓
6. 使用 access_token 获取用户信息
   API: /open-apis/authen/v1/user_info
```

### 2. JWT Session 管理

```typescript
// 创建 Session
const token = await new SignJWT(sessionData)
  .setProtectedHeader({ alg: 'HS256' })
  .setIssuedAt()
  .setExpirationTime('30d')
  .sign(secretKey);

// 验证 Session
const verified = await jwtVerify(token, secretKey);
const sessionData = verified.payload;
```

### 3. Cookie 设置

```typescript
cookies().set('admin_session', token, {
  httpOnly: true,        // 防止 JavaScript 访问
  secure: isProduction,  // 生产环境仅 HTTPS
  sameSite: 'lax',      // 防止 CSRF
  expires: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000),
  path: '/',
});
```

## 📊 性能优化

### 1. Middleware 优化
- 仅在必要路径执行验证
- 使用 matcher 精确匹配
- 避免不必要的重定向

### 2. Session 缓存
- JWT 无需服务器端存储
- 客户端自包含验证
- 减少数据库查询

### 3. API 调用优化
- 仅在回调时调用飞书 API
- 用户信息存储在 Session
- 减少外部 API 依赖
