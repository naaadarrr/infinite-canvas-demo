# Keyboard Shortcuts — @tc/infinite Canvas Widget

> Last updated: 2026-03-16

## 视图 (View)

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Scroll` | 平移画布 | 滚轮平移 |
| `⌘ + Scroll` | 缩放画布 | 按住 ⌘ 滚轮缩放 |
| `Pinch` | 缩放画布 | 触控板双指缩放 |
| `⌘ +` / `⌘ =` | 放大 | 增大缩放级别（拦截浏览器缩放） |
| `⌘ −` | 缩小 | 减小缩放级别（拦截浏览器缩放） |
| `⇧ 1` / `F` | 适应画布 | 所有内容适应到屏幕 |
| `⇧ 2` | 缩放到选中素材 | 有选中则定位到选中；无选中则适应全部 |

## 工具 (Tools)

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `V` | 选择工具 | 切换到选择/编辑模式 |
| `H` | 抓手工具 | 切换到平移模式 |
| `Space` + 拖拽 | 临时抓手 | 按住空格临时切换到平移；松开恢复 |

## 选择 (Selection)

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `⇧ + Click` | 加选/减选 | 按住 Shift 点击素材添加到选区 |
| `⌘ + A` | 全选 | 选择画布上所有素材 |
| 框选拖拽 | 框选 | 在空白处拖拽框选 |

## 编辑 (Edit)

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `⌘ + C` | 复制 | 复制选中的素材 |
| `⌘ + V` | 粘贴 | 粘贴素材 |
| `Delete` / `Backspace` | 删除 | 删除选中的素材（单选和多选均支持） |

## 多选操作 (2+ 素材选中)

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `⇧ H` | 水平等距分布 | 选中 2+ 素材时可用 |
| `⇧ V` | 垂直等距分布 | 选中 2+ 素材时可用 |
| `⇧ A` | 自动排列 | 选中 2+ 素材时自动网格排列 |

## 其他

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `/` 或 `?` | 快捷键面板 | 打开/关闭快捷键参考面板 |

---

## 备注

- `⌘` 指 macOS 的 Command 键；Windows/Linux 上对应 `Ctrl`。
- `⇧` 指 Shift 键。
- 所有单键快捷键（F、V、H）仅在画布区域聚焦且光标不在输入框内时生效。
- 视图类快捷键在编辑和只读模式下均可使用；工具和编辑类快捷键需要编辑权限。
- `⌘+` / `⌘-` 会拦截浏览器原生页面缩放，改为控制画布缩放。
- Shift+数字快捷键通过 capture 阶段监听，确保不被 React Flow 的 Shift 多选模式拦截。

## 设计原则

1. **不拦截浏览器标签页/导航快捷键**：不使用 `⌘+0/1/2/.../9`、`⌘+T/W/R/L` 等浏览器保留的组合键。
2. **⌘+/- 用于画布缩放**：与 Figma 行为一致，拦截浏览器页面缩放，改为画布缩放。
3. **Shift+数字用于视图操作**：参考 Figma 惯例（Shift+1 适应全部、Shift+2 聚焦选中）。
4. **面板只展示已实现的功能**。
