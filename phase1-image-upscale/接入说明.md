# Phase 1: Image Upscale 接入说明

## 概述

Image Upscale 是一个简单的表单型工具：上传图片 -> 选择目标分辨率(1K/2K/4K) -> 生成。

**技术栈匹配情况：**
- Recoil (recoil-next)：**完全一致**，不需要改
- Tailwind：**完全一致**，不需要改
- tRPC：**需要替换**，本仓库用 tRPC 包装 API，目标仓库无 tRPC，需改为直接调 axios/fetch

## 接入步骤

### Step 1: 复制文件

将本目录下所有 `.ts`/`.tsx` 文件复制到目标项目对应位置，建议放在：
```
你的项目/src/app/board/[id]/components/ToolPanel/feature/Image/ImageUpscale/
```

### Step 2: 替换 API 层（最关键的改动）

原仓库通过 tRPC 调用 API：

```typescript
// 原：data/task/useMutations.ts
import { trpc } from '@/lib/trpc/client';
export function useCreateImageUpscaleTaskMutation() {
  return wrapMutation(trpc.imageUpscale.createTask.useMutation());
}
```

**你需要改为直接调 API**。参考 `api-service.ts`（已从原仓库提取）：

```typescript
// 改：直接用 axios 或 fetch
import axios from 'axios';

// 创建任务 API
// POST /common_task/image_upscale/submit
export const createImageUpscaleTask = (params: {
  boardTaskId: string;
  inputImagePath: string;
  resolution: '1k' | '2k' | '4k';
  source?: string;
}) => axios.post('/common_task/image_upscale/submit', params).then(r => r.data);

// 查询任务 API
// GET /common_task/image_upscale/detail?taskId=xxx
export const queryImageUpscaleTask = (taskId: string) =>
  axios.get('/common_task/image_upscale/detail', { params: { taskId } }).then(r => r.data);
```

然后在 `hooks/useImageUpscaleTaskGeneration.ts` 中，将：
```typescript
const taskId = await createImageUpscaleTaskMutation.mutateAsync(params);
```
改为：
```typescript
const result = await createImageUpscaleTask(params);
const taskId = result.result; // API 返回 { code, message, result: "taskId" }
```

### Step 4: 注册到侧边栏

在你项目的工具面板配置中添加：

```typescript

// 在 TOOL_COMPONENTS 映射中添加

```

### Step 5: 验证

1. 侧边栏点击 Image Upscale，应显示上传区 + 分辨率选择 + Generate 按钮
2. 上传图片后预览正常
3. 选择分辨率（1K/2K/4K）正常切换
4. 点击 Generate 调用 API 正常

## API 接口文档

### 创建任务

```
POST /common_task/image_upscale/submit

Body:
{
  "boardTaskId": "string",        // 必填，Board 任务 ID
  "inputImagePath": "string",     // 必填，输入图片 S3 路径
  "resolution": "1k" | "2k" | "4k", // 必填，目标分辨率
  "source": "board"               // 可选，任务来源
}

Response:
{
  "code": "0",
  "message": "ok",
  "result": "task_123456"         // 返回任务 ID
}
```

### 查询任务

```
GET /common_task/image_upscale/detail?taskId=task_123456

Response:
{
  "code": "0",
  "message": "ok",
  "result": {
    "taskId": "task_123456",
    "status": "success" | "processing" | "failed",
    "inputImagePath": "s3://...",
    "inputImageUrl": "https://cdn.../input.jpg",
    "outputImagePath": "s3://...",
    "outputImageUrl": "https://cdn.../output.jpg",
    "gmtCreate": "2025-01-01T00:00:00Z",
    ...
  }
}
```
