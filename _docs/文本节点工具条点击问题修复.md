# 文本节点工具条点击问题修复

## 问题描述

文本节点的工具条（Toolbar）无法点击，按钮和各种功能都无法使用。从浏览器的 Element 面板可以看到工具条一直在不断重新渲染，导致无法捕获点击事件。

## 问题分析

### 根本原因（通过 Debug Mode 运行时证据确认）

**主要问题：组件无限重新渲染循环**

通过运行时日志分析发现：
- TextNode 组件在短时间内渲染了数千次
- TextToolbar 组件也在疯狂重新渲染
- 日志文件在几秒内达到 14,788 行，约 6MB

**具体原因：**

1. **事件处理函数未 memoized（核心问题）**
   - `handleFontSizeChange`, `handleFontWeightChange` 等函数每次渲染都创建新引用
   - 导致 TextToolbar 接收到新的 props，触发重新渲染
   - 形成无限循环：TextNode 渲染 → 创建新函数 → TextToolbar 渲染 → 触发父组件更新 → TextNode 渲染

2. **TextToolbar 组件未优化**
   - 没有使用 `React.memo` 包装，无法跳过不必要的重新渲染

3. **z-index 层级不足（次要问题）**
   - 工具条的 `z-index: 100` 不够高，可能被其他节点或画布层遮挡
   - 下拉菜单的 `z-index: 101` 也不够高

4. **事件传播未完全阻止（次要问题）**
   - 虽然工具条有 `stopPropagation()`，但缺少 `preventDefault()`
   - 所有按钮和交互元素都需要阻止事件冒泡和默认行为

5. **透明度滑块事件处理错误**
   - `<input type="range">` 的 `onPointerDown` 和 `onMouseDown` 调用了 `preventDefault()`
   - 阻止了滑块的默认拖动行为，导致无法操作

## 修复方案

### 1. 使用 React.useCallback 包装事件处理函数（核心修复）

```typescript
const handleFontSizeChange = React.useCallback((newSize: number) => {
  nodeData.onNodeDataChange?.(nodeData.id, { fontSize: newSize });
}, [nodeData]);

const handleFontWeightChange = React.useCallback((newWeight: 'normal' | 'bold') => {
  nodeData.onNodeDataChange?.(nodeData.id, { fontWeight: newWeight });
}, [nodeData]);

const handleTextAlignChange = React.useCallback((newAlign: TextAlign) => {
  nodeData.onNodeDataChange?.(nodeData.id, { textAlign: newAlign });
}, [nodeData]);

const handleBackgroundColorChange = React.useCallback((newColor: string | undefined) => {
  nodeData.onNodeDataChange?.(nodeData.id, { backgroundColor: newColor });
}, [nodeData]);

const handleBackgroundOpacityChange = React.useCallback((newOpacity: number) => {
  nodeData.onNodeDataChange?.(nodeData.id, { backgroundOpacity: newOpacity });
}, [nodeData]);
```

**效果：** 函数引用在 `nodeData` 不变时保持稳定，避免触发 TextToolbar 不必要的重新渲染。

### 2. 使用 React.memo 包装 TextToolbar 组件


**效果：** 只有当 props 真正变化时才重新渲染，配合 useCallback 大幅减少渲染次数。

### 3. 修复透明度滑块事件处理

```typescript
<input
  type="range"
  min={0}
  max={100}
  value={Math.round(backgroundOpacity * 100)}
  onChange={(event) => {
    event.stopPropagation();  // 只阻止冒泡，不阻止默认行为
    onBackgroundOpacityChange(Number(event.target.value) / 100);
  }}
  onPointerDown={(e) => {
    e.stopPropagation();  // 移除 preventDefault()
  }}
  onMouseDown={(e) => {
    e.stopPropagation();  // 移除 preventDefault()
  }}
  onClick={(e) => {
    e.stopPropagation();
  }}
  style={{ width: 90, accentColor: '#ffffff' }}
/>
```

**效果：** 滑块可以正常拖动，同时不会触发画布的拖拽事件。

### 4. 提高 z-index 层级

```typescript
// 工具条主容器
zIndex: 9999,  // 从 100 提升到 9999

// 字体大小下拉菜单
zIndex: 10000, // 从 101 提升到 10000
```

### 5. 添加完整的事件处理

为所有交互元素添加：
- `preventDefault()` - 阻止默认行为（按钮类元素）
- `stopPropagation()` - 阻止事件冒泡

```typescript
onPointerDown={(e) => {
  e.preventDefault();
  e.stopPropagation();
}}
onMouseDown={(e) => {
  e.preventDefault();
  e.stopPropagation();
}}
onClick={(e) => {
  e.preventDefault();
  e.stopPropagation();
  // 实际的点击处理逻辑
}}
```

### 6. 明确设置 pointerEvents

```typescript
style={{
  // ... 其他样式
  pointerEvents: 'auto',
}}
```

### 7. 优化失焦处理

```typescript
const handleBlur = (event: React.FocusEvent<HTMLTextAreaElement>) => {
  // 延迟检查，给工具栏按钮点击事件时间执行
  setTimeout(() => {
    const relatedTarget = event.relatedTarget as HTMLElement;
    if (relatedTarget && containerRef.current?.contains(relatedTarget)) {
      // 点击的是工具栏内的元素，重新聚焦
      textareaRef.current?.focus();
      return;
    }
    
    setIsEditing(false);
    if (!content.trim()) {
      nodeData.onNodeDataChange?.(nodeData.id, { _delete: true } as any);
    }
  }, 0);
};
```

## 技术要点

### React 性能优化最佳实践

1. **使用 React.useCallback 稳定函数引用**
   - 对于传递给子组件的回调函数，必须使用 `useCallback` 包装
   - 依赖数组要准确，避免过度依赖导致频繁重新创建

2. **使用 React.memo 优化组件渲染**
   - 对于纯展示组件或工具栏组件，使用 `React.memo` 包装
   - 配合 `useCallback` 使用效果最佳

3. **避免在事件处理中阻止默认行为**
   - 对于 `<input type="range">` 等原生交互元素，不要调用 `preventDefault()`
   - 只阻止事件冒泡 `stopPropagation()`，保留默认行为

### 事件处理优先级

1. `onPointerDown` - 最早触发，用于阻止指针事件
2. `onMouseDown` - 鼠标按下时触发
3. `onClick` - 点击完成后触发，执行实际逻辑

### z-index 层级规划

- 画布层: 1-99
- 节点层: 100-999
- 工具条层: 9999+
- 下拉菜单层: 10000+

### React Flow 事件类名

- `nodrag` - 阻止拖拽
- `nopan` - 阻止平移
- `nowheel` - 阻止滚轮缩放

这些类名需要添加到所有交互元素上，防止 React Flow 捕获事件。
