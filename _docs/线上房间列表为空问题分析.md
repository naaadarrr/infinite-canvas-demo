# 线上房间列表为空问题分析

## 问题描述

1. **房间列表为空**: 迁移到线上后,管理面板的房间列表显示为空
2. **R2 数据缺失**: R2 存储中只有 1月23日的数据,之后创建的画布数据都没有保存到 R2
3. **DO 数据未同步**: 虽然有 DO 实例在运行,但无法从中获取房间列表信息

## 代码架构分析

### 1. 数据存储架构

当前系统使用三层存储架构:

```
┌─────────────────────────────────────────────────────────┐
│                   Durable Objects (DO)                   │
│  ┌────────────────────────────────────────────────────┐ │
│  │            DO Storage (主存储)                      │ │
│  │  - 完整画布状态 (nodes, seq, commandIds 等)        │ │
│  │  - 低延迟,自动持久化                                │ │
│  │  - 每 2 秒自动 flush                                │ │
│  └────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
                          ↓
         ┌────────────────┴────────────────┐
         ↓                                  ↓
┌──────────────────┐              ┌──────────────────┐
│   D1 Database    │              │   R2 Storage     │
│   (元数据)        │              │   (已废弃)        │
├──────────────────┤              ├──────────────────┤
│ - canvas ID      │              │ - 快照备份        │
│ - title          │              │ - 仅用于迁移      │
│ - latest_seq     │              │ - 不再写入新数据   │
│ - updated_at     │              └──────────────────┘
│ - created_at     │
└──────────────────┘
```

### 3. D1 记录创建逻辑

文件: `packages/server/src/canvasRoom.ts` (第 369-411 行)

```typescript
private async ensureD1Record(): Promise<void> {
  if (!this.canvasId) return;
  
  // 如果已经确保过,跳过(避免重复写入)
  if (this.d1RecordEnsured) {
    return;
  }
  
  try {
    // 检查是否已存在
    const existing = await this.env.DB.prepare(
      'SELECT id FROM canvases WHERE id = ?'
    ).bind(this.canvasId).first();
    
    if (!existing) {
      // 不存在,创建新记录
      await this.env.DB.prepare(
        'INSERT INTO canvases (id, title, latest_seq, created_at, updated_at) VALUES (?, ?, ?, unixepoch(), unixepoch())'
      ).bind(this.canvasId, this.canvasId, this.seq).run();
    } else {
      // 已存在,更新 updated_at
      await this.env.DB.prepare(
        'UPDATE canvases SET updated_at = unixepoch(), latest_seq = ? WHERE id = ?'
      ).bind(this.seq, this.canvasId).run();
    }
    
    this.d1RecordEnsured = true;
  } catch (error) {
    console.error(`[CanvasRoom] Error ensuring D1 record:`, error);
    throw error;
  }
}
```

**关键点**: 
- `ensureD1Record()` 在 DO 初始化时调用
- 使用 `d1RecordEnsured` 标志避免重复写入
- 如果 D1 写入失败,会抛出错误但不会阻塞初始化

## 问题根因分析

### 问题 1: 房间列表为空

**根因**: D1 数据库中没有房间记录

可能的原因:

1. **D1 数据库未正确初始化**
   - 线上环境的 D1 数据库可能没有执行 schema 初始化
   - 检查: `wrangler.toml` 中的 `database_id` 是否正确

2. **D1 写入失败但被静默处理**
   - `ensureD1Record()` 在 `initialize()` 中被 try-catch 包裹
   - 如果写入失败,只会打印警告,不会阻塞 DO 初始化
   ```typescript
   try {
     await this.ensureD1Record();
   } catch (error) {
     console.warn(`[CanvasRoom] Failed to ensure D1 record:`, error);
     // 不阻塞初始化流程
   }
   ```

3. **DO 实例在 D1 记录创建前被销毁**
   - 如果用户快速打开并关闭页面,DO 可能在 `ensureD1Record()` 完成前就被销毁
   - 空房间超时设置为 60 秒,可能不够时间完成 D1 写入

4. **D1 数据库权限问题**
   - 线上环境的 Worker 可能没有 D1 写入权限
   - 需要检查 Cloudflare 控制台的权限配置

### 问题 2: R2 数据缺失

**根因**: R2 存储已被废弃,不再写入新数据

这是**预期行为**,不是 bug:

1. **架构变更**: 系统已从 R2 快照模式迁移到 DO Storage 模式
2. **R2 仅用于迁移**: 只在 DO 初始化时读取 R2 中的历史数据
3. **新数据存储位置**: 所有新数据都存储在 DO Storage 中

R2 中只有 1月23日的数据,说明:
- 1月23日之前使用的是 R2 快照模式
- 1月23日之后切换到了 DO Storage 模式
- 1月23日之后的数据都在 DO Storage 中,不在 R2 中

#### R2 数据为什么看不到?

**技术原因**:

1. **R2 写入代码已废弃**
   
   文件: `packages/server/src/canvasRoom.ts` (第 1836-1839 行)
   ```typescript
   private async saveSnapshotNow(): Promise<void> {
     // 已废弃: 现在使用 flushToStorage
     // 保留空实现以防其他地方调用
   }
   ```
   
   原本负责保存 R2 快照的方法已经变成空实现,不再执行任何操作。

2. **数据持久化流程已改变**
   
   **旧流程** (1月23日之前):
   ```
   DO 内存状态 → 定期保存快照到 R2 → 更新 D1 指针
   ```
   
   **新流程** (1月23日之后):
   ```
   DO 内存状态 → 每 2 秒 flush 到 DO Storage → 更新 D1 元数据
   ```
   
   文件: `packages/server/src/canvasRoom.ts` (第 1736-1776 行)
   ```typescript
   private async flushToStorage(reason: 'scheduled' | 'final' | 'manual'): Promise<void> {
     if (!this.isDirty || !this.canvasId) return;
     
     // 使用 blockConcurrencyWhile 保证原子性写入
     await this.state.blockConcurrencyWhile(async () => {
       await this.state.storage.put('state', {
         version: this.CURRENT_STATE_VERSION,
         seq: this.seq,
         nodes: Array.from(this.nodes.values()),
         canvasId: this.canvasId,
         commandIds: Object.fromEntries(this.processedCommandIds),
         tombstones: Object.fromEntries(this.externalTombstones),
         autoLayoutIndex: this.autoLayoutIndex,
         lastFlushedAt: Date.now(),
       });
     });
     
     // 同时更新 D1 记录(不阻塞主流程)
     this.updateD1Record().catch(err => {
       console.warn(`[CanvasRoom] Failed to update D1 record:`, err);
     });
   }
   ```
   
   注意: 这里只写入 `this.state.storage` (DO Storage),**完全没有调用 R2 相关的方法**。

3. **R2 仅用于读取历史数据**
   
   R2 现在只在一个地方被读取:
   
   文件: `packages/server/src/canvasRoom.ts` (第 314-340 行)
   ```typescript
   // DO Storage 为空时,尝试从 R2+D1 迁移(仅一次)
   const snapshot = await loadLatestSnapshot(this.env, canvasId);
   
   if (snapshot) {
     // 从 R2 加载历史数据
     this.seq = snapshot.seq;
     this.nodes = new Map(snapshot.nodes.map(node => [node.id, node]));
     
     // 立即写入 DO Storage,完成迁移
     await this.state.storage.put('state', { ... });
     
     console.log(`[CanvasRoom] Migration completed, data now in DO storage`);
   }
   ```
   
   这个迁移逻辑只在 DO 首次初始化且 DO Storage 为空时执行一次。

4. **R2 只保留用于删除操作**
   
   文件: `packages/server/src/index.ts` (第 283-288 行)
   ```typescript
   // 删除画布时,同时删除 R2 中的快照
   const prefix = `snapshots/${canvasId}/`;
   const listed = await env.R2.list({ prefix });
   for (const obj of listed.objects) {
     await env.R2.delete(obj.key);
   }
   ```
   
   这是唯一还在使用 R2 的地方,用于清理历史数据。

**结论**:

R2 中看不到新数据是**完全正常**的,因为:
- ✅ 新架构不再向 R2 写入数据
- ✅ 所有新数据都在 DO Storage 中
- ✅ R2 只用于历史数据迁移和删除
- ✅ DO Storage 提供更好的性能和一致性

**如果需要查看数据**,应该:
1. 通过管理 API 查看 DO 状态: `GET /admin/rooms/{roomId}`
2. 查看 D1 数据库: `wrangler d1 execute canvas_db --command "SELECT * FROM canvases"`
3. DO Storage 数据无法直接查看,但会在 DO 初始化时自动加载

### 问题 3: 无法从 DO 获取房间列表

**根因**: Cloudflare 不提供直接列出所有 DO 实例的 API

技术限制:
- Durable Objects 是按需创建的
- 没有全局 API 可以列出所有活跃的 DO 实例
- 必须通过外部索引(如 D1)来追踪房间列表

当前的解决方案:
- 使用 D1 作为房间索引
- DO 初始化时在 D1 中创建记录
- 管理面板从 D1 查询房间列表

## 需要解决的问题

### 核心问题

1. **D1 记录创建失败**
   - 优先级: 🔴 高

   - 优先级: 🟢 低

   - 优先级: 🟢 低

## 解决方案建议

### 方案 1: 修复 D1 记录创建 (立即执行)

**目标**: 确保所有新房间都能在 D1 中创建记录

**步骤**:

1. **增强错误处理**
   ```typescript
   private async ensureD1Record(): Promise<void> {
     if (!this.canvasId) return;
     
     if (this.d1RecordEnsured) {
       return;
     }
     
     try {
       const existing = await this.env.DB.prepare(
         'SELECT id FROM canvases WHERE id = ?'
       ).bind(this.canvasId).first();
       
       if (!existing) {
         const result = await this.env.DB.prepare(
           'INSERT INTO canvases (id, title, latest_seq, created_at, updated_at) VALUES (?, ?, ?, unixepoch(), unixepoch())'
         ).bind(this.canvasId, this.canvasId, this.seq).run();
         
         // 验证写入是否成功
         if (!result.success) {
           throw new Error(`D1 insert failed: ${JSON.stringify(result)}`);
         }
         
         console.log(`[CanvasRoom] ✅ Created D1 record for room ${this.canvasId}`);
       } else {
         await this.env.DB.prepare(
           'UPDATE canvases SET updated_at = unixepoch(), latest_seq = ? WHERE id = ?'
         ).bind(this.seq, this.canvasId).run();
         
         console.log(`[CanvasRoom] ✅ Updated D1 record for room ${this.canvasId}`);
       }
       
       this.d1RecordEnsured = true;
     } catch (error) {
       // 记录详细错误信息
       console.error(`[CanvasRoom] ❌ Error ensuring D1 record for ${this.canvasId}:`, {
         error: error.message,
         stack: error.stack,
         canvasId: this.canvasId,
         seq: this.seq,
       });
       
       // 重新抛出错误,让调用方决定如何处理
       throw error;
     }
   }
   ```

2. **添加重试机制**
   ```typescript
   private async ensureD1RecordWithRetry(maxRetries = 3): Promise<void> {
     for (let i = 0; i < maxRetries; i++) {
       try {
         await this.ensureD1Record();
         return; // 成功则返回
       } catch (error) {
         console.warn(`[CanvasRoom] D1 record attempt ${i + 1}/${maxRetries} failed:`, error);
         
         if (i === maxRetries - 1) {
           // 最后一次重试失败,记录错误但不阻塞
           console.error(`[CanvasRoom] Failed to ensure D1 record after ${maxRetries} attempts`);
           return;
         }
         
         // 等待后重试
         await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
       }
     }
   }
   ```

3. **在多个时机确保 D1 记录**
   ```typescript
   // 初始化时
   private async initialize(canvasId: string): Promise<void> {
     // ...
     await this.ensureD1RecordWithRetry();
   }
   
   // 第一个用户加入时
   private async handleJoin(ws: WebSocket, message: JoinMessage): Promise<void> {
     // ...
     if (this.connections.size === 1 && !this.d1RecordEnsured) {
       await this.ensureD1RecordWithRetry();
     }
   }
   
   // 定期持久化时
   private async flushToStorage(reason: string): Promise<void> {
     // ...
     if (!this.d1RecordEnsured) {
       await this.ensureD1RecordWithRetry();
     }
   }
   ```

### 方案 2: 数据修复脚本 (立即执行)

**目标**: 为现有的 DO 实例补充 D1 记录

**实现**: 创建管理 API 端点

```typescript
// packages/server/src/admin.ts

/**
 * 手动为房间创建 D1 记录
 */
export async function handleCreateRoomRecord(
  request: Request,
  env: Env
): Promise<Response> {
  const auth = await verifyAdminToken(request, env);
  if (!auth.success) {
    return new Response(JSON.stringify({ error: auth.error }), { status: 401 });
  }
  
  try {
    const { roomId } = await request.json();
    
    if (!roomId) {
      return new Response(JSON.stringify({ error: 'roomId is required' }), { status: 400 });
    }
    
    // 获取 DO 实例
    const id = env.CANVAS_ROOM.idFromName(roomId);
    const stub = env.CANVAS_ROOM.get(id);
    
    // 调用 DO 的状态 API 获取当前状态
    const statusUrl = new URL(`https://dummy.com/admin/status`);
    const statusResponse = await stub.fetch(statusUrl.toString());
    const status = await statusResponse.json();
    
    // 检查 D1 中是否已存在
    const existing = await env.DB.prepare(
      'SELECT id FROM canvases WHERE id = ?'
    ).bind(roomId).first();
    
    if (existing) {
      // 更新记录
      await env.DB.prepare(
        'UPDATE canvases SET updated_at = unixepoch(), latest_seq = ? WHERE id = ?'
      ).bind(status.seq || 0, roomId).run();
      
      return new Response(JSON.stringify({
        success: true,
        action: 'updated',
        roomId,
        seq: status.seq,
      }));
    } else {
      // 创建新记录
      await env.DB.prepare(
        'INSERT INTO canvases (id, title, latest_seq, created_at, updated_at) VALUES (?, ?, ?, unixepoch(), unixepoch())'
      ).bind(roomId, roomId, status.seq || 0).run();
      
      return new Response(JSON.stringify({
        success: true,
        action: 'created',
        roomId,
        seq: status.seq,
      }));
    }
  } catch (error) {
    console.error('[Admin] Error creating room record:', error);
    return new Response(JSON.stringify({
      success: false,
      error: error.message,
    }), { status: 500 });
  }
}
```

**目标**: 自动发现并修复缺失的 D1 记录

**限制**: 由于无法列出所有 DO 实例,需要从其他来源获取房间 ID 列表

**可能的来源**:
1. R2 中的快照文件 (可以列出所有 `snapshots/` 下的目录)

**实现示例**:

```typescript
/**
 * 从 R2 扫描所有房间并修复 D1 记录
 */
export async function handleScanAndFixRooms(
  request: Request,
  env: Env
): Promise<Response> {
  const auth = await verifyAdminToken(request, env);
  if (!auth.success) {
    return new Response(JSON.stringify({ error: auth.error }), { status: 401 });
  }
  
  try {
    const roomIds = new Set<string>();
    
    // 从 R2 扫描所有房间
    const listed = await env.R2.list({ prefix: 'snapshots/' });
    
    for (const obj of listed.objects) {
      // 解析 key: snapshots/{roomId}/{seq}.json
      const match = obj.key.match(/^snapshots\/([^\/]+)\//);
      if (match) {
        roomIds.add(match[1]);
      }
    }
    
    const results = [];
    
    // 为每个房间检查并创建 D1 记录
    for (const roomId of roomIds) {
      try {
        const existing = await env.DB.prepare(
          'SELECT id FROM canvases WHERE id = ?'
        ).bind(roomId).first();
        
        if (!existing) {
          // 尝试从 DO 获取状态
          const id = env.CANVAS_ROOM.idFromName(roomId);
          const stub = env.CANVAS_ROOM.get(id);
          const statusUrl = new URL(`https://dummy.com/admin/status`);
          const statusResponse = await stub.fetch(statusUrl.toString());
          const status = await statusResponse.json();
          
          // 创建 D1 记录
          await env.DB.prepare(
            'INSERT INTO canvases (id, title, latest_seq, created_at, updated_at) VALUES (?, ?, ?, unixepoch(), unixepoch())'
          ).bind(roomId, roomId, status.seq || 0).run();
          
          results.push({ roomId, action: 'created', seq: status.seq });
        } else {
          results.push({ roomId, action: 'skipped', reason: 'already exists' });
        }
      } catch (error) {
        results.push({ roomId, action: 'failed', error: error.message });
      }
    }
    
    return new Response(JSON.stringify({
      success: true,
      total: roomIds.size,
      results,
    }));
  } catch (error) {
    console.error('[Admin] Error scanning and fixing rooms:', error);
    return new Response(JSON.stringify({
      success: false,
      error: error.message,
    }), { status: 500 });
  }
}
```

## 总结

### 问题本质

1. **房间列表为空**: D1 数据库中没有房间记录,原因可能是:
   - D1 未初始化
   - D1 写入失败被静默处理
   - DO 实例在 D1 记录创建前被销毁

2. **R2 数据缺失**: 这是预期行为,R2 已废弃,新数据都在 DO Storage 中

3. **无法从 DO 获取列表**: 这是 Cloudflare 的技术限制,必须使用外部索引(D1)
